## 常见问题

**马来西亚区账号能登 iCloud 吗？**
卖家页面写的是不要登，只用于 App Store 下载。苹果这边，Apple ID 是访问全部苹果服务的账号，登了 iCloud 就意味着照片、备份、查找都挂在这个号上，而这个号并不在你名下。

**会被封吗？**
页面承认存在“官方回收和停用”，并且声明平台不负责找回。苹果对外的说法是账号被锁定、停用或禁用时可以走恢复访问的流程，但能不能恢复、多久恢复由苹果按自己的规则处理，和卖家无关。没有人能给你一个封号概率，说能给的都在猜。

**能改密码吗？**
能。凭密保问题与答案可以改密码、绑邮箱和手机号。这也是为什么那四样信息比账号本身更值得保管好。

**3 天之后出问题怎么办？**
页面给的答案是没有售后。账号类商品的售后期就是自购买日起 3 天，过期后账号被盗、被回收、密码失效，平台都不接手。

**和市面上“已开通 iCloud 的马来西亚独享号”有什么区别？**
确实有商家在卖宣称已开通 iCloud 的马来西亚独享账号，但公开信息里没有可核验的价格和条款，没法做实质对比。可以确定的是，Accountboy 这个 $3.97 的马来西亚档，页面明确要求不要登 iCloud。
